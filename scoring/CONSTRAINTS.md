# Scientist Constraints

## Data

Use the Gripper instances generated by `data/gripper.py`: training instances
with 3, 4, and 5 balls, and held-out test instances with 6 through 30 balls.
Do not add external planning domains or train on the held-out instances.

## Policy Interface

Submit a policy artifact in the same JSON format as
`outputs/genex_gripper/policy.json`. The evaluator must be able to execute the
policy using only `data/` and `eval/`, without importing the submitting method.

## Resource Scale

Keep the same object capacity and action dynamics. Do not improve scores by
changing the problem generator, increasing the test-time search budget, or
calling a planner during evaluation.

## Compliance Checklist

- [ ] Training uses only the generated 3, 4, and 5 ball instances
- [ ] Evaluation uses the unchanged 6 through 30 ball held-out instances
- [ ] Policy JSON can be scored by `scripts/evaluate.sh`
- [ ] No planner call or external search is used by the policy at evaluation time
- [ ] Gripper action dynamics and gripper capacity are unchanged
