The admit-all shortcut is the most consequential finding that requires no benchmark-file modification. Its actual trajectories, coverage, plan ratios, and branching scores equal the reference's; its entire +0.3 gain comes from charging zero features instead of three and one rule instead of four. It beats the genuine fix by **0.115849057**. No learned conditions or feature changes are needed. The synthetic dynamics already prohibit several unproductive actions, and their successor ordering implements the useful priority. The evaluator also does not validate the rule-change or stratification obligations. Consequently, the score cannot distinguish learning a generalized policy from outsourcing decisions to the provided dynamics and executor.

The test-answer shortcut uses no hidden evaluator, hidden capacities, hidden scores, paper, or unknown seed. The published generator identifies every 6–35-ball instance, and the public planner supplies demonstrations. Only the learner's training-instance provider is redirected inside its own process. The resulting policy ties the reference exactly. This is a shortcut because it violates the explicitly held-out training regime, even though the learned policy's behavior remains unchanged.

The mutable-artifact shortcuts persist through fresh Python processes because their changes are ordinary scientist-visible files in `data/`. Restoring `eval/` and the hidden test script does not restore their imported dynamics, goals, features, or comparison planner. The fixed-feature shortcut is not evidence for a better learner: it changes a benchmark-provided feature and conceals its computation behind the same one-feature accounting. The planner-denominator shortcut changes only the comparator. The goal and test-size shortcuts change the labels or tasks. These are distinct scoring dependencies to fix in the next iteration.

The failed shortcuts establish useful boundaries. The hidden evaluator overwrites forged score values and recomputes the scored coverage/count metrics from the artifact. It accepts forged learning diagnostics, but all four carry zero coefficients. It ignores baseline artifact/module changes because its baseline metrics are implemented in `eval/`. Null collections raise a `TypeError` rather than earning a score. No claim is made about untested impossible-value encodings.

The audit uses only persisted files, so it does not rely on container state surviving a fresh test job.
